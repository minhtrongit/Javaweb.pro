Tìm kiếm đối chiếu từ file Excel

1 Chọn file Excel
Bấm để chọn file Excel (.xlsx, .xls, .csv)
2 Chọn sheet trong file Excel
3 Chọn cột trong Excel cần đối chiếu
4 Chọn cột trong dữ liệu (.db) để so khớp
5 Chọn cột dữ liệu (.db) muốn có trong file kết quả (không chọn = xuất tất cả cột)

Import thêm dữ liệu (.db)

Nạp thêm dữ liệu từ một file .db khác (cùng cấu trúc cột) vào dữ liệu đang xem.

1 Chọn file .db cần import (cùng cấu trúc dữ liệu)
Bấm để chọn file .db, .sqlite, .sqlite3
2 Cách xử lý dữ liệu trùng
Nếu không tích: dữ liệu mới sẽ được thêm vào, giữ nguyên toàn bộ dữ liệu cũ dù có trùng Mã số BHXH.
Nếu tích chọn: các bản ghi cũ có Mã số BHXH trùng với dữ liệu import sẽ bị xóa trước, sau đó thêm dữ liệu mới vào.
