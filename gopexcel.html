thành 1 file duy nhất

Chọn nhiều file hoặc cả một thư mục, chọn chế độ gộp phù hợp, công cụ sẽ tạo ra 1 file Excel kết quả — tự động tách sang sheet mới nếu vượt quá 900.000 dòng để không vượt giới hạn của Excel.

Dữ liệu xử lý hoàn toàn trên máy bạn — không gửi lên máy chủ nào
01

Chọn chế độ gộp

Chọn 1 trong 4 chế độ tuỳ theo cấu trúc file nguồn của bạn.

Ví dụ tiêu đề nằm ở dòng 1–3 thì nhập 3.

02

Thêm file Excel nguồn

Chấp nhận .xlsx / .xlsm / .xltx / .xltm / .xls. File đang mở dở (tên bắt đầu bằng "~$") sẽ tự động bị bỏ qua.

Kéo thả file vào đây, hoặc

    Chưa có file nào được thêm.

    03

    Đặt tên file kết quả & bắt đầu gộp

    Kết quả sẽ tự tải về máy. Dữ liệu lớn có thể tách thành nhiều file — trình duyệt sẽ hỏi xác nhận, hãy chọn "Cho phép" (Allow) để tải hết.

    Dữ liệu lớn (vd 1 triệu dòng) sẽ tự động chia thành nhiều file _1, _2... và tải về lần lượt để tránh trình duyệt hết bộ nhớ. Giảm số này nếu vẫn bị lỗi "Out of Memory".

    Sẵn sàng

    Toàn bộ quá trình gộp file diễn ra ngay trên trình duyệt của bạn (không upload lên server). File lớn hoặc nhiều file có thể mất một chút thời gian xử lý tuỳ cấu hình máy.
