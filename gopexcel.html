All File Excel → One File Excel

Gộp nhiều file Excel thành 1 file duy nhất

Chọn nhiều file hoặc cả một thư mục, chọn chế độ gộp phù hợp, công cụ sẽ tạo ra 1 file Excel kết quả.

Dữ liệu xử lý hoàn toàn trên máy bạn — không gửi lên máy chủ nào
01

Chọn chế độ gộp

Chọn 1 trong 5 chế độ tuỳ theo cấu trúc file nguồn của bạn.

Ví dụ tiêu đề nằm ở dòng 1–3 thì nhập 3.

Cách nhau bởi dấu phẩy — hệ thống tự tìm và gộp các sheet trùng tên này ở tất cả file (không phân biệt hoa/thường). Dùng cách này nếu không muốn tự tick chọn từng sheet. Ở bước 2 bên dưới, mỗi file sẽ có nút "+" để bạn tự tick chọn sheet riêng cho file đó — nếu đã tick chọn riêng cho 1 file thì lựa chọn riêng sẽ được ưu tiên áp dụng cho file đó thay vì danh sách tên ở đây.

02

Thêm file Excel nguồn

Chấp nhận .xlsx / .xlsm / .xltx / .xltm / .xls. File đang mở dở (tên bắt đầu bằng "~$") sẽ tự động bị bỏ qua. Ở chế độ 5️⃣ Chọn Sheet, mỗi file sẽ có nút "+" để mở danh sách sheet và tick chọn sheet cần gộp.

Kéo thả file vào đây, hoặc

    Chưa có file nào được thêm.

    03

    Đặt tên file kết quả & bắt đầu gộp

    Kết quả sẽ tự tải về máy. Dữ liệu lớn có thể tách thành nhiều file — trình duyệt sẽ hỏi xác nhận, hãy chọn "Cho phép" (Allow) để tải hết.

    Dữ liệu lớn (vd 1 triệu dòng) sẽ tự động chia thành nhiều file _1, _2... và tải về lần lượt. Nếu 1 phần vẫn quá lớn để tạo (dữ liệu quá dài), công cụ sẽ tự động chia đôi và ghi lại — không cần bạn tự dò số phù hợp.

    Sẵn sàng

    Toàn bộ quá trình gộp file diễn ra ngay trên trình duyệt của bạn (không upload lên server). File lớn hoặc nhiều file có thể mất một chút thời gian xử lý tuỳ cấu hình máy.
