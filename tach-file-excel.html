Tách File Excel

Chia nhỏ file Excel
theo dòng hoặc theo nhóm.

Tải lên một file Excel, chọn cách tách phù hợp, chọn cột muốn giữ lại — mọi thứ xử lý ngay trên trình duyệt, dữ liệu không rời khỏi máy của bạn.

Bước 1

Chọn file Excel nguồn

Kéo thả file vào đây, hoặc bấm để chọn
Hỗ trợ .xlsx, .xls, .csv
Bước 2

Số dòng dữ liệu mỗi file

dòng / file (không tính dòng tiêu đề)
Mỗi file kết quả sẽ có đầy đủ dòng tiêu đề gốc, và tối đa số dòng bạn nhập ở trên.
